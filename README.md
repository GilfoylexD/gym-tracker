# Gym Tracker

Новая версия приложения лежит в `index.html`. Она же используется для Render.

## Файлы

- `index.html` — приложение.
- `icon-512.png` — иконка для BotFather.
- `render.yaml` — конфигурация Render Static Site.
- `server.py` — старый локальный сервер для теста через ngrok. **В `.gitignore`, в GitHub не попадает.**
- `index.old-2026-11-22-1656.html` — резервная копия предыдущей версии.

## Локальный запуск

```powershell
python server.py
```

Сервер слушает порт **5501**. В сообщении скрипта написано `ngrok http 5500` — это опечатка, для ngrok указывай `5501`.

`server.py` содержит токен бота прямо в коде. Не публикуй его и не коммить в GitHub. Если файл уже куда-то попадал — перевыпусти токен в BotFather.

## Деплой на Render

Приложению не нужен сервер: это статический сайт.

1. Загрузи в GitHub только `index.html`, `icon-512.png`, `render.yaml`, `README.md` (без `server.py`).
2. Render Dashboard → **New → Static Site** (или **New → Blueprint**).
3. Build Command — пустой, Publish Directory — `.`.
4. Render выдаст адрес `https://<имя>.onrender.com`; корень сайта уже отдаёт `index.html`.
5. В BotFather → `/myapps` укажи этот HTTPS-адрес как Web App URL.

Static Site на Render бесплатен, работает по HTTPS через CDN и не засыпает, в отличие от free Web Service. Для личного трекера этого достаточно.

## Данные

- История хранится в `localStorage` и привязана к адресу.
- `localhost:5501`, ngrok и Render — разные origin, поэтому данные между ними автоматически не переносятся.
- Перед переездом сделай **«ДАННЫЕ» → «Сохранить файл»**, а на новом адресе — **«ДАННЫЕ» → «Загрузить из файла»**.
- На новом адресе приложение автоматически подставит 9 базовых тренировок из заметок с 10 повторениями.
